# Contributing

Thank you for improving PyOrbit. For a lesson change, read [the authoring guide](docs/content/authoring.md), edit content in `content/courses`, and run `make content`. For code changes, run `make check` before opening a pull request. Keep changes focused and describe the learner problem they solve.

Content must be original or appropriately licensed. Do not add executable MDX/HTML, personal data, credentials, or claims about functionality that does not exist. A maintainer reviews educational correctness, accessibility, and code safety before merging.

For bugs, use the GitHub bug report template. For vulnerabilities, follow [SECURITY.md](SECURITY.md) instead of opening a public issue.
