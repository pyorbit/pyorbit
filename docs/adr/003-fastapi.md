# ADR 003: Python API with FastAPI

**Status:** Accepted

FastAPI on Python 3.13 handles future user data. Pydantic v2 settings, SQLAlchemy 2 typed models, Alembic, and PostgreSQL provide a conventional Python stack that also models good Python practices for learners. Public content remains in the web build. OpenAPI will be used to generate TypeScript contracts when browser-consumed endpoints arrive.
