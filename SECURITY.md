# Security policy

Please do not open public issues for vulnerabilities. Use GitHub's private vulnerability reporting for this repository, or contact the maintainers privately through their GitHub profiles if reporting is unavailable. Include impact, reproduction steps, and affected versions. Do not test against other users or production data.

The project is early-stage and has no published support window. No endpoint accepts Python for execution. The `/preview` page is a local UI prototype and does not run code.
